# Skill: Testes — Desenvolvimento Guiado por Testes (TDD)

Use esta skill quando o usuário solicitar criar features ou corrigir bugs seguindo TDD ("teste primeiro").

## Ciclo TDD
1. **Vermelho (Red):** Escrever um teste automatizado que expresse o comportamento esperado e falhe.
2. **Verde (Green):** Escrever o código mínimo necessário para fazer o teste passar.
3. **Refatorar (Refactor):** Melhorar a clareza e estrutura do código mantendo todos os testes verdes.
