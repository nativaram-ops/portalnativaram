# Skill: Engenharia — Melhorar Arquitetura

Use esta skill para avaliar a saúde arquitetural da base de código.

## Focos de Melhoria
- Módulos profundos: interfaces simples que escondem complexidade substancial.
- Eliminação de dependências circulares.
- Redução de acoplamento temporal e estrutural.
