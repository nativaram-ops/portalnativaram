# Skill: Atualizar Status

Use esta skill quando o usuário pedir para mudar o status ou prioridade de um projeto.

## Status permitidos

- ideia
- planejamento
- em andamento
- pronto
- em manutenção
- pausado
- travado
- abandonado

## Prioridades permitidas

- alta
- média
- baixa
- contínua/obrigatória

## Passos

1. Identifique o projeto.
2. Encontre a nota.
3. Atualize apenas o campo Status e/ou Prioridade.
4. Registre a mudança no Histórico.

## Regras

- Não altere outros campos sem pedido.
- Se o novo status não estiver entre os permitidos, escolha o mais próximo e informe.
- Se houver ambiguidade, pergunte.

## Resposta final

Informe:
- projeto
- status/prioridade antigo, se estava claro
- status/prioridade novo
