# Skill: Testes — Configurar Pre-Commit

Use esta skill para adicionar validações automáticas no momento do commit.

## Ferramentas
- Husky para orquestração de hooks do Git.
- Lint-staged para executar lint e testes apenas nos arquivos modificados.
- Checagem estrita de TypeScript (`tsc --noEmit`).
