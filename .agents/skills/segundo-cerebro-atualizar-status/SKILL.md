# Skill: Segundo Cérebro — Atualizar Status

Use esta skill quando o usuário solicitar explicitamente para alterar o status de um projeto ou documento no vault.

## Objetivo
Manter os metadados de status sincronizados e válidos de acordo com o esquema do Segundo Cérebro.

## Status Permitidos
- `ideia`
- `planejamento`
- `em andamento`
- `pronto`
- `em manutenção`
- `pausado`
- `travado`
- `abandonado`

## Passo a Passo
1. Localize a nota em `Segundo-Cerebro/`.
2. Verifique o campo `status:` no frontmatter YAML.
3. Atualize para o novo status solicitado.
4. Registre brevemente no corpo da nota se houver uma justificativa para a mudança.
