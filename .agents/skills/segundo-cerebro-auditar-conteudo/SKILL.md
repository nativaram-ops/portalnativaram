# Skill: Segundo Cérebro — Auditar Conteúdo Mockado

Use esta skill ao ser solicitado para realizar auditoria, revisão de integridade ou limpeza de dados temporários no vault.

## Diretrizes
- Nunca invente dados.
- Onde faltar informação concreta, substitua por "A definir".
- Verifique se links internos `[[Nome da Nota]]` apontam para notas existentes.
- Garanta que não existam trechos longos de código dentro do vault (o código fica no repositório).
