# Skill: Engenharia — Revisão de Código

Use esta skill quando o usuário solicitar: "revise o código", "faça um code review", "revise o PR" ou "revise as mudanças desde o commit X".

## Eixos de Análise
1. **Padrões (Standards):** O código respeita os padrões arquiteturais, TypeScript estrito, design tokens e convenções do projeto?
2. **Especificação (Spec):** O código cumpre exatamente os requisitos solicitados sem adicionar complexidade desnecessária?
3. **Conformidade Regulatória (Nativaram):** O código viola alguma regra semântica (ANVISA, CONAD 01/2010, Meta Ads)?
