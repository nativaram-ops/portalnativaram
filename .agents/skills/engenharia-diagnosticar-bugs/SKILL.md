# Skill: Engenharia — Diagnóstico de Bugs

Use esta skill quando o usuário disser "diagnostique", "debugue este erro", ou reportar que algo está quebrado, lento ou falhando.

## Ciclo de Diagnóstico
1. **Reprodução Mínima:** Isolar o gatilho exato do erro.
2. **Coleta de Evidências:** Inspecionar logs, stack traces e processos órfãos.
3. **Hipótese:** Formular uma explicação científica para a falha antes de alterar código.
4. **Verificação & Correção:** Corrigir a causa raiz (não apenas o sintoma) e validar.
