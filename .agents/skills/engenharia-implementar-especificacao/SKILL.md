# Skill: Engenharia — Implementar Especificação

Use esta skill para transformar um documento de especificação ou issue em código pronto para produção.

## Passos
1. Ler e compreender toda a especificação técnica antes de escrever código.
2. Identificar dependências e contratos de interface.
3. Implementar de baixo para cima (tipos -> lógica -> componentes -> integração).
4. Validar compilação com `npm run build` e testes.
