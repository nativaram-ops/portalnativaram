# Skill: Auditar Conteúdo Mockado

Use esta skill quando o usuário pedir para verificar se ainda existe conteúdo fictício, genérico ou mockado no vault.

## Objetivo

Encontrar e remover/substituir conteúdo que não represente projetos reais do usuário.

## Passos

1. Pesquise dentro de Segundo-Cerebro/.
2. Procure sinais de conteúdo mockado:
   - Projeto Exemplo
   - Cliente Exemplo
   - Lorem ipsum
   - Tarefa exemplo
   - Vídeo exemplo
   - Produto fictício
   - Placeholder genérico desnecessário
   - Qualquer conteúdo que pareça inventado
3. Liste os arquivos suspeitos.
4. Se o usuário pediu para corrigir diretamente, remova ou substitua.
5. Preserve campos “A definir”, pois eles são permitidos.

## Regras

- Não apagar informação real.
- Não tratar “A definir” como mockado.
- Não apagar estrutura útil.
- Se houver dúvida se algo é real, pergunte.

## Resposta final

Informe:
- arquivos verificados
- conteúdo mockado encontrado
- conteúdo removido/substituído
- dúvidas pendentes
