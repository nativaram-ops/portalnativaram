# Skill: Segundo Cérebro — Atualizar Projeto

Use esta skill quando o usuário pedir para adicionar informações, tarefas, features, status ou relações a uma nota de projeto existente no vault.

## Objetivo
Atualizar uma nota existente dentro de `Segundo-Cerebro/` seguindo as diretrizes de YAML simples e relações no corpo.

## Passo a Passo
1. Identifique o projeto citado pelo usuário.
2. Localize a nota correspondente dentro de `Segundo-Cerebro/`.
3. Leia o arquivo antes de editar.
4. Identifique a seção correta para a nova informação.
5. Se for uma relação, insira na seção `## Relações` utilizando subtítulos padronizados (`### Depende de`, `### Alimenta / impulsiona`, etc.).
6. Preserve o restante do arquivo sem sobrescrever informações reais.

## Resposta Final
Informe os arquivos alterados, o resumo da mudança e eventuais pendências.
