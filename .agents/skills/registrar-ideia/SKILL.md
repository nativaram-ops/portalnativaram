# Skill: Registrar Ideia

Use esta skill quando o usuário quiser registrar uma ideia solta.

## Objetivo

Guardar ideias reais sem transformar tudo automaticamente em projeto.

## Local padrão

Segundo-Cerebro/00-Inbox/Inbox.md

## Formato recomendado

## Ideia - Título curto

Data: AAAA-MM-DD  
Área relacionada: A definir  
Status: ideia  

Descrição:
...

Próximo passo:
- [ ] A definir

## Regras

- Não crie projeto novo a menos que o usuário peça.
- Não invente detalhes.
- Se a ideia tiver relação clara com um projeto, adicione link interno.
- Se a área não estiver clara, use “A definir”.

## Resposta final

Informe:
- ideia registrada
- arquivo atualizado
