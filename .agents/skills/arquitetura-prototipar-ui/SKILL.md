# Skill: Arquitetura — Prototipar UI

Use esta skill para construir protótipos funcionais rápidos que validem a experiência visual antes do código final.

## Requisitos de Design Nativaram
- Tokens: Floresta (`#16281E`), Âmbar (`#D4A359`), Areia (`#F8F6F0`), Pedra (`#1C1917`).
- Tipografia: Cinzel para títulos solenes e Inter para textos corridos.
- Microanimações elegantes e acessibilidade WCAG 2.1 AA.
