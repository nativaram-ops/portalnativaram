# Skill: Produtividade — Sabatina de Decisões (Grill Me)

Use esta skill quando o usuário pedir para estressar um plano, avaliar pontos cegos ou sabatinar uma decisão.

## Postura do Agente
- Faça perguntas desafiadoras sobre premissas não comprovadas.
- Explore cenários de falha, custos ocultos e manutenção futura.
- Ajude a lapidar o plano até que ele seja à prova de falhas.
