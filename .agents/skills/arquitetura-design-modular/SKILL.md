# Skill: Arquitetura — Design Modular

Use esta skill ao projetar novas fronteiras de módulos, bibliotecas internas ou seções do sistema.

## Princípios de Módulos Profundos
- Uma interface pequena e intuitiva deve encapsular uma grande quantidade de funcionalidade.
- Esconder detalhes de implementação atrás de contratos estáveis.
- Evitar módulos rasos (pass-throughs) que apenas aumentam a carga cognitiva.
