# Skill: Registrar Decisão

Use esta skill quando o usuário disser que decidiu algo sobre um projeto.

## Objetivo

Registrar decisões importantes no projeto correto.

## Passos

1. Identifique o projeto.
2. Encontre a nota do projeto.
3. Adicione a decisão em “Decisões importantes”.
4. Se fizer sentido, adicione também em “Histórico”.

## Formato

- AAAA-MM-DD: decisão tomada.

## Regras

- Não altere status automaticamente, a menos que o usuário peça.
- Não invente motivo da decisão.
- Se o projeto não estiver claro, pergunte.

## Resposta final

Informe:
- decisão registrada
- projeto atualizado
